# 🎓 StudyFlow AI — Your Smart Study Companion

StudyFlow AI is a student-friendly study planning platform designed to help learners organize their academic work, manage study time, track progress, and stay motivated.

From school students to undergraduate learners, StudyFlow AI makes studying more organized, productive, and enjoyable.

## ✨ Features

- **Student Dashboard:** View study progress and important statistics in one place.
- **Task Management:** Add, complete, and delete study tasks.
- **Study Schedule:** Generate and manage study schedules.
- **Focus Timer:** Use focused study sessions with automatic break sessions.
- **Daily Study Goals:** Track daily study time and maintain study streaks.
- **Study Analytics:** Monitor total study time, completed tasks, pending tasks, and weekly activity.
- **Rewards & Achievements:** Earn points and unlock badges as you complete tasks.
- **User Authentication:** Sign up, log in, and log out securely.
- **Personalized Data:** Keep tasks and study progress separate for each student account.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/dasaridniharika-dotcom/StudyFlow--AI.git
```

### 2. Open the project

```bash
cd StudyFlow--AI
```

Open the project folder in Visual Studio Code.

### 3. Configure Supabase

- Create a Supabase project.
- Configure the required database tables and Row Level Security policies.
- Open `js/supabase.js`.
- Add your Supabase project URL and publishable key.

**Important:** Never expose your Supabase service-role key or other secret credentials in frontend code.

### 4. Run the application

Open `index.html` using a local development server, such as the VS Code Live Server extension.
